# Vintage FX

Two 12-bit sampler colours for single pads or the whole mix.

- **Pad**: open **Sample Editor** and click **VINTAGE: OFF**. The button then
  reads **FX:** plus the model, and colours only that pad.
- **Global**: click **VINTAGE** under **GLOBAL MIXER** in the main view. It
  colours the main output and every extra output.

## Models

- **Off**: no processing.
- **GSP1200 Sampler**: drum-machine colour with a voicing row: **Sweep** (filter
  moves on each hit), **Dark**, **Mid**, **Open**, **Bright**, **Raw** (no filter).
- **GS950 Unit**: rack-sampler colour with a steep filter and **Resonance**.

Choosing a model resets **Rate** to its default. The GSP1200 Sampler model is
separate from the **GSP** button, which is a pitch mode.

## Knobs

**Bits**, **Rate**, **Drive**, **Tone** (moves the filter), **Mix**, and
**Resonance** (GS950 Unit only).

Drag up or down, or use the wheel. Double-click or middle-click resets a knob.
Click outside, **X** or **Escape** closes the panel. Selecting another pad,
changing view or arming also closes it.

## Saving and undo

Both are saved with the project. Pad changes can be undone; global changes
cannot. Neither is available for host automation. Export Processed does not
apply Vintage. Buttons are unavailable while armed.
